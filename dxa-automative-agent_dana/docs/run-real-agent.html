Chạy agent thật: từ bật máy đến câu trả lời

“Agent thật” ở đây là workflow Dana được nạp, Gemini thật viết câu trả lời, còn Python tìm nguồn và kiểm nội dung. Chạy app lên chưa đủ để xác nhận cả ba phần đang hoạt động.

1 · Chuẩn bị

Windows, Python 3.12+, mạng Internet và Gemini API key hợp lệ. Lấy key ở Google AI Studio.

2 · Bấm run.bat

Lần đầu tạo môi trường .venv và cài Dana/thư viện; nhập key khi được hỏi. Chờ tới dòng máy chủ chạy ở cổng 8000.

3 · Mở giao diện

run.bat tự mở trình duyệt; nếu chưa mở, vào http://localhost:8000. Bật “Để Gemini viết câu trả lời”.

Key được lưu trong .env ở máy chạy DXA; không gửi key vào chat, không commit file .env lên Git. Lần chạy sau, launcher dùng lại key đã lưu.

Đúng chế độ Gemini: nhập câu hỏi có trong dữ liệu → giao diện ghi “Gemini viết từ các case bên phải” (answered_by=llm), có nguồn, không có cảnh báo fallback.
Chưa phải câu trả lời Gemini: thiếu/sai key, lỗi Dana/Gemini hoặc kiểm thất bại → có thể dùng offline/template/Python; đọc dòng cảnh báo trong UI và cửa sổ terminal.

Xác nhận trước khi demo hoặc bàn giao

A · Kiểm tra dịch vụ và index

Mở endpoint health. Cần thấy ok=true, engine=dana, có số cases/chunks/videos. mode=gemini xác nhận vector Gemini đã nạp; mode này tự nó chưa chứng minh câu trả lời được Gemini viết.

http://localhost:8000/health

B · Kiểm tra một câu trả lời thật

Hỏi một câu có trong kho, ví dụ “Bình xăng con chảy xăng khi dựng xe”. Xác nhận nhãn “Gemini viết từ các case bên phải”, nguồn video hiện đúng và không có cảnh báo agent fallback.

POST /ask → answered_by: "llm" · warnings: []
Nếu health báo offline: xem key trong .env, kiểm tra internet rồi khởi động lại để chạy build_gemini.py. Nếu giao diện nói ghép khuôn/Python: xem cảnh báo ở terminal; dxa_dana tự fallback khi workflow lỗi. API key và số liệu chi phí phụ thuộc tài khoản Google AI Studio.
Luồng thật cần xác nhận: Dana workflow được nạp + retrieval có nguồn + Gemini trả lời (answered_by=llm) + kiểm chống bịa qua + nguồn mở đúng video. Nếu thiếu một bước, chưa nên gọi đó là lần chạy Gemini end-to-end.
